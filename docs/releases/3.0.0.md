# 记得闪卡 3.0.0 发布说明

## 版本定位

3.0.0 将原有单次 AI 制卡请求升级为应用内轻量 Agent，并加入独立的 AI 改卡能力。Agent 本身运行在 ArkTS 应用层；本次没有修改 Anki Rust 源码、protobuf 定义、NAPI ABI 或数据库结构。

## AI 制卡

- 由用户选择目标牌组和笔记类型，支持普通问答、完形填空以及导入牌组中的自定义笔记类型。
- Agent 先读取笔记类型的真实字段、模板和完形能力，不再依赖“填空题”等显示名称猜测结构。
- 明确要求张数时校验最终合法草稿数量；完形填空会进一步校验标记所在字段，年份填空要求会校验每张草稿包含四位年份完形标记。
- 所有新卡先成为可编辑草稿，用户可以修改字段、自由勾选并确认保存。
- 没有真实草稿时不会把模型正文中的“已经生成”当作成功。

## AI 改卡

- 从首页或新建牌组面板进入时，Agent 可在用户发送消息后按授权工具搜索卡库。
- 从学习页当前卡片或浏览器选中内容进入时，页面会在本地预载目标上下文；进入页面本身不会请求 API。
- 支持提出字段、标签和目标牌组修改草稿，并展示同一笔记生成的其他卡片所受影响。
- 删除、迁移笔记类型、修改模板或 CSS 属于高风险操作，需要两次独立确认。
- 真正写入前重新读取 baseline；若目标已经变化则停止，避免用过期草稿覆盖新内容。
- 部分项目执行失败时，只为失败目标生成新的重试草稿，不重复已经成功的写入。

## Agent 与工具体系

- `AgentRunner` 使用有界 Provider/工具循环，支持取消、瞬时网络重试、输出截断续跑、工具失败纠错与重复失败熔断。
- `AgentToolCatalog` 是模型可见工具说明的唯一来源，同时提供 JSON Schema、规范调用模板和禁止规则。
- `AgentScope` 在每条用户消息前重建；模型只能引用入口上下文或本轮读取工具登记过的稳定 ID。
- `AgentDraftExecutor` 是唯一写入边界，并且只调用应用既有 ArkTS 服务。
- 页面展示可见正文、Provider 实际提供的思考摘要、工具过程、HTTPS 来源和草稿；不伪造或暴露模型隐藏思维。
- 工具参数和结果默认折叠，但允许展开查看经过脱敏、截断的完整安全记录；历史不会保存 API 密钥、原始隐藏推理、媒体字节、旧确认令牌或可重复执行的旧草稿。

## 提供商、模型与联网

- DeepSeek 为默认提供商，提供固定官方 HTTPS 地址和 Flash、Pro、视觉实验模型下拉。
- OpenAI 使用固定官方 HTTPS Responses 端点和模型下拉。
- Custom 可输入自定义 HTTPS 地址与模型名，但接口必须兼容 Responses 协议，不进行静默协议降级。
- 应用记忆提供商和各提供商的模型选择；API 密钥加密保存在设备本地，普通偏好中只保存非敏感设置。
- 用户要求联网时，只有 Provider 返回真实搜索事件和 HTTPS 来源才算成功；Custom 默认不宣称支持联网。

## 安全边界

- 模型不能直接调用 Anki Rust、裸 protobuf、NAPI、数据库、文件系统、shell 或任意 RPC。
- 创建目标锁定为界面选择的牌组与笔记类型；AI 不能在未授权范围内自行写入。
- 普通写入需要一次确认；高风险写入需要二次确认，确认令牌与草稿和风险级别绑定、短时且一次性。
- 单轮 Provider 与工具调用均有上限；批量写入受设置上限约束。
- 不支持的媒体能力会明确降级或拒绝，不会把图片、音频字节无条件发送给文本模型。

## 已完成验证

- Node 完整契约测试覆盖 Agent 协议、SSE、工具 Schema、作用域、安全策略、草稿执行、失败重试、入口和界面契约。
- Rust 双架构、ArkTS 编译、HAP 打包和签名的完整构建已通过。
- 两台 HarmonyOS 模拟器已覆盖安装 3.0.0 签名 HAP，并确认 `versionCode=3000`、`versionName=3.0.0`。
- 模拟器在线 DeepSeek 场景曾验证：精确生成 5 张中国现代史年份完形草稿、含糊请求生成合法草稿、导入自定义笔记类型在字段纠错后生成草稿。

## 发布前仍需验收

- 实体手机上的普通、完形、自定义导入笔记类型制卡全流程。
- 学习页当前卡片和浏览器选中内容的 AI 改卡真实写入，以及高风险二次确认。
- 断网、恢复、取消、Provider 不支持联网和长输出续传。
- OpenAI 在线请求；当前仅有协议和自动化测试证据。
- Type-in-the-Answer 输入框的局部主题在实体手机对应卡型上的视觉回归。
- 通用 Agent 暂不创建图片遮罩；该能力需要独立的结构化媒体/遮罩工具。
