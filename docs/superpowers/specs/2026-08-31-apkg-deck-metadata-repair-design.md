# APKG 牌组元数据修复设计

## 问题

`D:\Projects\anki制卡\.azure_build.py` 在为缺少顶层牌组记录的 APKG 补建根牌组时，
把 `lrnToday`、`revToday`、`newToday`、`timeToday` 写成了数字 `0`。Anki 26.05 的
schema 11 要求这些字段为二元数组，因此导入时报 `decoding decks: JsonError`。

受影响的分发版为：中考英语词汇、高考英语词汇、CET 四六级词汇、CET 四六级谐音助记版。

## 修复

1. 将生成脚本补建根牌组时的四个字段统一写为 `[0, 0]`。
2. 增加自动化校验，要求每条牌组记录的四个字段均为长度为 2 的整数数组。
3. 仅重新打包四个受影响的 APKG，复用现有数据库内容与 Azure TTS 音频，不重新生成音频。
4. 不修改记得闪卡客户端，不操作云盘。

## 验证

- 先让校验在现有四个错误包上失败，证明测试能捕获该问题。
- 修正脚本并重新打包后，四个包全部通过元数据校验。
- 对四个输出执行 ZIP CRC、SQLite `integrity_check`、媒体映射完整性和卡片数量校验。
- 记录新文件的大小与 SHA-256，供替换云端文件时核对。
