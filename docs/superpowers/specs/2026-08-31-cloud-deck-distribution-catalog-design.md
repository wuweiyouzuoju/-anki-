# 云端分发版牌组目录设计

## 目标

让 `hosting/cloud-decks.json` 与 123 云盘当前实际存在的公开文件一致。软件界面继续显示正常牌组名，不向用户展示文件名中的“（分发版）”；下载地址、精确文件大小和卡片数必须对应实际 APKG。

## 目录内容

目录保持 `schemaVersion: 1`，最终提供六个公开牌组：

| ID | 软件显示名 | 云盘文件 | 版本 | 卡片数 | 字节数 |
| --- | --- | --- | --- | ---: | ---: |
| `cet-46-vocabulary` | CET四六级词汇 | `CET四六级词汇（分发版）.apkg` | `1.1.0` | 14311 | 169033353 |
| `high-school-english-vocabulary` | 高考英语词汇 | `高考英语词汇（分发版）.apkg` | `1.1.0` | 8453 | 89347750 |
| `middle-school-english-vocabulary` | 中考英语词汇 | `中考英语词汇（分发版）.apkg` | `1.1.0` | 3305 | 44392978 |
| `ai-machine-learning` | AI机器学习 | `AI机器学习（分发版）.apkg` | `1.1.0` | 1450 | 5526001 |
| `it-computer` | IT计算机 | `IT计算机（分发版）.apkg` | `1.0.0` | 3400 | 35303280 |
| `china-law-professional` | 中国法律专业版 | `中国法律专业版.apkg` | `1.0.0` | 2500 | 1351898 |

四个已有牌组保留原 ID，避免把同一牌组误判成全新条目。它们的分发包已经替换媒体来源，文件内容发生变化，因此展示版本提升为 `1.1.0`。

`IT计算机` 是独立牌组，不能沿用已下架的 `ai-computer-terms`：前者为 3400 张卡片，后者为 2190 张。目录删除失效的“AI计算机专业工具名词术语”，新增 ID `it-computer`。

用户已从云盘删除 `AI for Science（分发版）.apkg`，目录不得包含该牌组。

中国法律专业版保持原文件、ID 和版本。经 APKG 审计，其 `media` 映射为空，不包含 MP3 或其他媒体文件。

## 数据流与失败边界

客户端继续从既有 `云端牌组目录地址` 获取 JSON，不修改应用网络代码。每个条目的 `downloadUrl` 指向 123 云盘公开 HTTPS 直链。客户端下载后仍按目录中的精确 `size` 校验文件，并执行已有 ZIP/APKG 文件头校验。

只修改本地发布源、对应契约测试和托管说明。云盘上传、删除或替换不在本次本地修改中；生成文件验证通过后由用户上传替换 `cloud-decks.json`。

## 首次引导选择限制

首次云端牌组引导最多同时选择 3 个牌组，至少仍需成功导入 1 个才能进入软件。选择上限在首页的选择状态入口统一执行，不能只依赖复选框外观；取消已选牌组始终允许。

用户已经选满 3 个后点击第 4 个时，该牌组不进入已选列表，并显示本地化提示“最多选择 3 个牌组”。下载入口也必须防御性拒绝超过 3 个 ID 的异常状态，确保实际下载任务数不会突破上限。

弹窗顶部使用小字号提示：“最多选择 3 个牌组。更多牌组文件可前往官方 QQ 群 726837065 免费下载（点击复制）”。群号继续沿用现有点击复制能力，不新增 QQ 唤起或外部跳转。

## 验证

- 目录模型可以成功解析更新后的 JSON。
- 契约测试锁定六个条目的顺序、ID、显示名、版本、大小和卡片数。
- 交互测试锁定最多选择 3 个、点击第 4 个时提示且不加入、取消选择后可以改选其他牌组，以及下载入口不会处理超过 3 个牌组。
- 中英文资源键保持一致，中文顶部小字明确包含“最多选择 3 个”和“QQ群免费下载更多牌组文件”的含义。
- 所有下载地址均为 123 云盘 HTTPS 直链，解码后的文件名与上表一致。
- 对当前云端可访问文件执行只读请求，核对 HTTP 成功状态和 `Content-Length`；若 CDN 尚未刷新，明确报告而不修改云端文件。
- 完整运行项目测试，确认目录调整没有破坏其他功能。
