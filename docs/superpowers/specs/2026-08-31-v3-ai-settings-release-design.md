# 记得闪卡 3.0.0 与 AI 配置界面调整设计

> 归档状态：这是一次性历史设计/执行记录，不是当前路线图、待办列表或操作手册。未勾选项不表示仍未实现；当前事实请查阅 [文档导航](../../README.md)、[开发状态](../../DEVELOPMENT_PLAN.md)、[当前架构](../../architecture.md) 和实际源码/测试。


## 目标

将当前发布版本、正式公告和对应契约统一为 3.0.0，并简化 AI 制卡/改卡配置界面，使中文文案、模型选择、输入框样式和标题位置一致。

## 发布版本

- `AppScope/app.json5` 使用 `versionName: '3.0.0'` 与 `versionCode: 3000`。
- 当前正式公告使用新的 3.0.0 ID、双语标题、发布日期和版本范围。
- 3.0.0 公告以 AI 制卡/改卡 Agent 为主要内容，同时保留云端牌组、公告、AnkiWeb 与图片遮罩等重要更新摘要。
- 更新直接约束当前版本与正式公告的测试。既有 2.3.3 设计文档属于历史记录，不做机械改写。

## 提供商与模型

- 中文界面的 `Custom` 显示为“自定义”，英文仍显示 `Custom`。
- DeepSeek 下拉提供 `deepseek-v4-flash`、`deepseek-v4-pro` 与 `deepseek-v4-flash-vision-exp`。
- 保持 DeepSeek 默认提供商和 `deepseek-v4-flash` 默认模型不变。
- 不静默替换用户选择的模型；提供商拒绝模型时展示真实错误。

## 配置界面

- 右上角“AI 配置”改为“配置”。
- 删除 Responses API/Asset Store 提示、数据发送说明、同意复选框及相应发送/保存前置拦截。
- API 密钥、自定义 HTTPS 地址和自定义模型名称使用相同高度、背景色、边框、圆角、文字色、占位文字色和左右内边距。
- AI 页面内配置区和设置页 AI Agent 分组保持相同视觉规则。
- 自定义地址仍必须是 HTTPS，自定义模型名称仍不能为空；密钥继续保存在 Asset Store。

## 标题布局

- AI 制卡与 AI 改卡共享顶部栏。
- 顶部栏分为左右等宽区域与中间标题区域：左侧放返回，右侧放历史与配置。
- 标题固定在屏幕水平中线，不因左右按钮宽度不同而偏移；空间不足时标题省略，不覆盖按钮。

## 安全边界

- 删除提示与复选框只简化界面，不改变“用户点击发送后才请求 AI”的行为。
- 不改变草稿确认、二次高风险确认、scope、批量上限、baseline 冲突检查、Asset Store 密钥或唯一写执行器。
- 不修改 Anki Rust、protobuf、NAPI ABI 或数据库结构。

## 验证

- 契约测试覆盖 3.0.0 版本、3.0.0 公告、DeepSeek 三模型、中文“自定义”、无隐私勾选拦截、输入框统一样式与标题居中结构。
- 运行完整 `npm test` 与 `npm run build:app`。
- 仅使用 `hdc install -r` 覆盖安装模拟器，并目视检查 AI 制卡和 AI 改卡页面。
