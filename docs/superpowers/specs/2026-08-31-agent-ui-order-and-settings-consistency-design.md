# Agent 消息顺序与设置样式一致性设计

> 归档状态：这是一次性历史设计/执行记录，不是当前路线图、待办列表或操作手册。未勾选项不表示仍未实现；当前事实请查阅 [文档导航](../../README.md)、[开发状态](../../DEVELOPMENT_PLAN.md)、[当前架构](../../architecture.md) 和实际源码/测试。


## 目标

让 AI 制卡结果遵循实际生成过程，并让工具详情与设置页使用现有统一交互：工具详情默认折叠，草稿位于过程信息之后，AI 智能体设置卡片与其他设置分组完全同款。

## 已确认设计

- AI 消息内部固定顺序为：正文、思考过程、工具过程、来源、卡片/变更草稿、保存或应用操作、批次结果。
- 新产生和从历史恢复的工具追踪均默认折叠；用户在当前页面展开后，完成/失败状态更新不得把它重新折叠。
- 工具追踪箭头照搬设置分组：固定字符 `▼`、11fp、弱化文字色，展开为 0 度、折叠为 -90 度，150ms `Curve.EaseOut` 旋转。
- 新增 `设置分组卡片` 公共组件，使用 `@BuilderParam` 承载展开内容，集中管理标题、可选帮助按钮、背景、16vp 内边距、12vp 圆角和旋转箭头。
- 外观、调度器、布局、同步、AI、术语、数据以及设置页内联的数据库/关于/实验分组迁移到该组件；各业务组件只传标题、深色状态、展开状态、回调和内容槽。
- 不修改各设置项业务内容、Agent 工具协议、草稿写入、Anki Rust、protobuf、NAPI ABI 或数据库结构。

## 验证

- 契约测试明确检查 trace 默认 `expanded: false`、消息布局源码顺序、工具箭头旋转动画，以及所有设置分组不再持有重复标题栏/卡片样式。
